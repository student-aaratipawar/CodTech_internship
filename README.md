Task 1 - Sales Trend Visualization 

A data analytics project that analyzes sales data to identify trends, patterns, and key business insights. The project uses Python-based data analysis and visualization techniques to understand sales performance and present meaningful insights through charts and graphs.

Technologies Used
Python, Pandas, Matplotlib, Seaborn, Data Analysis, Data Visualization


Task 2 - Market Basket Analysis

A data analytics project that analyzes customer transaction data to identify frequently purchased products and discover relationships between items. The project uses association rule mining to find product combinations and generate useful insights for product recommendations, cross-selling, and business decision-making.

Technologies Used
Python, Pandas, MLxtend, Apriori Algorithm, Association Rule Mining, Data Analysis
